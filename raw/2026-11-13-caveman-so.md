What is Caveman Code?+−

Caveman Code is an app for Mac and the browser that runs every coding agent you use in one window: Claude Agent, Codex, Cursor and Caveman, our own agent, with a Chief that runs your chats for you. It is free on the subscriptions and keys you already have. Sign in to use it in the browser on a Cloud computer, or download the Mac app.

[See Caveman Code](https://caveman.so/code)

How can it cost less on the same model?+−

The harness around a model decides what every request carries and how many go out. Caveman, our own agent, runs on ours. On the same model, it finished Terminal-Bench 4 for 21% less than Codex, and day-long work across connected apps for 76% less than Claude Code. It did that on 31% fewer tokens than Codex per solved task, and 83% fewer than Claude Code per session. The runs and how we measured them are on the Caveman Code page.

[See how we measured](https://caveman.so/code#benchmarks)

Can I use the subscriptions I already pay for?+−

Yes. Your Claude plan runs as Claude Agent and your ChatGPT plan as Codex, each through its own app and login; Caveman Code never copies a password or token. Caveman, our own agent, takes any API key, a coding plan such as Kimi Code or GLM Coding Plan, a gateway such as OpenRouter, or your own endpoint. Caveman Code is free on your own keys and logins.

[See what you can bring](https://caveman.so/code#app)

What is Caveman Cloud?+−

Caveman Cloud is where your agents run and where you see and control them: spend, keys, policies and traces in one place. It is free for one person. Deploying the software factories you build with Caveman Code to Caveman Cloud is coming soon.

[See Caveman Cloud](https://caveman.so/cloud)

Can I keep my coding agent?+−

Yes. The open-source Caveman CLI wraps supported agents including Claude Code, Codex, and Gemini CLI. Shorter replies also work in agents such as Cursor. Support for shorter replies and for context compression differs by agent, so check the setup guide for yours before installing.

[Check your agent's setup](https://caveman.so/guides/coding-agent-setup)

Do I need a Caveman account?+−

Caveman Code and Caveman Cloud need an account, which you can open at app.caveman.so/signup. The open-source CLI, shorter replies and context compression work without one. You still need the credentials or subscription required by your model provider or coding agent. Adaptive model selection needs a free account.

[Set up the local tools](https://docs.caveman.so/caveman/quickstart)

Will fewer tokens lower my bill?+−

It depends on how you pay. Fewer billable tokens can reduce metered API spend, but cached input, retries, and recovery calls affect the result. A flat monthly subscription may cost the same. Compare total cost per successful task and check provider billing before claiming savings.

[Measure cost per successful task](https://caveman.so/guides/measure-agent-cost)
