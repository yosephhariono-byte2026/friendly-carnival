# Model pintar merencanakan, model murah mengerjakan

Pakai model paling pintar untuk menulis rencana, lalu model yang lebih cepat dan murah untuk mengerjakannya. Di Claude Code: Opus untuk rencana, Sonnet untuk implementasi. Model cepat sekarang sudah cukup cerdas, jadi cara ini hemat biaya tanpa banyak menurunkan hasil.

> "you would use the smart model to write the plan and then you would use a cheaper, faster model to implement it"
