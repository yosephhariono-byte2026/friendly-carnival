# Claude Code berjalan lokal, tapi isi file tetap bisa terkirim ke model

Claude Code mencari di komputer Anda tanpa mengunggah seluruh proyek dulu. Tetapi isi file yang perlu dibaca Claude untuk menjawab tetap dikirim ke model. Untuk kode perusahaan, pahami kebijakan data akun Anda dan aturan perusahaan soal alat AI.

> "So, Claude Code runs locally does not mean that everything always stays in my machine."
