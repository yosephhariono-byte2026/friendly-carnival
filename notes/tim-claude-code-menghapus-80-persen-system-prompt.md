# Tim Claude Code menghapus 80% system prompt-nya

Menurut Boris Cherny (pembuat Claude Code), setiap model baru keluar, tim menghapus dan mengubah banyak instruksi bawaan Claude Code, karena tiap model berbeda. Banyak instruksi lama hanya menambal kekurangan model sebelumnya; Opus 5 sudah melakukannya sendiri. Caranya disebut ablation: hapus semua instruksi, lalu kembalikan satu per satu untuk melihat dampak tiap baris. Temuannya: model sedikit lebih cerdas tanpa instruksi-instruksi itu.

> "So, yeah, we deleted 80% of the system prompt."
