# Periksa skill dan plugin sebelum dipasang

Skill dan plugin bisa berisi skrip, perintah, dan akses alat, bukan hanya teks. Baca SKILL.md dan skripnya sebelum memasang, dan hanya pasang dari sumber terpercaya. Skill yang tidak terpakai tetap memakan konteks, jadi hapus.

> "So, read the skill.md and any scripts before installing."
