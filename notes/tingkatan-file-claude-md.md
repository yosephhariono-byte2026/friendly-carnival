# CLAUDE.md punya beberapa tingkatan

Pribadi: ~/.claude/CLAUDE.md, berlaku di semua proyek. Proyek: CLAUDE.md di akar proyek, ikut di-commit agar seluruh tim sama. Lokal: file CLAUDE.local.md (subtitle: ".claud.local.md"), hanya untuk Anda di proyek itu (misalnya akun tes), tidak masuk Git. Di proyek besar bisa ada CLAUDE.md bertingkat di tiap folder, dimuat hanya saat Claude bekerja di bagian itu.

> "Claude supports different levels of instructions."
