# Caveman Code adalah aplikasi berbayar untuk banyak agen

Sekarang Caveman juga perusahaan (didukung Y Combinator) dengan aplikasi Mac dan web yang menjalankan Claude, Codex, Cursor, dan agen mereka sendiri dalam satu jendela. Gratis kalau memakai langganan sendiri; ada paket berbayar $20 sampai $200 per bulan. Mereka mengklaim 76% lebih murah dari Claude Code pada model yang sama, tetapi ini pengukuran mereka sendiri.
