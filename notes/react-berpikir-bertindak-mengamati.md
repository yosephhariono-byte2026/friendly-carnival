# ReAct: berpikir, bertindak, mengamati, ulangi

ReAct (2022) membuat model tidak hanya berpikir sekali lalu menjawab, tetapi berputar: pikir langkah berikutnya, bertindak (misalnya mencari), lihat hasilnya, pikir lagi. Dalam data yang ditunjukkan Diyi Yang (Stanford, CS329Z kuliah 1), kegagalan karena halusinasi pada ReAct nol, sedangkan pada chain of thought (berpikir langkah demi langkah tanpa mencari) 56%.

> "Hallucination, uh hallucinated the reasoning traces or facts, react is zero."
