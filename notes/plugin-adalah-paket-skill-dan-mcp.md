# Plugin adalah paket berisi skill dan MCP

Skill adalah satu proses. Plugin adalah paket yang bisa berisi skill sekaligus kemampuan lain seperti server MCP. Contoh: plugin resmi Stripe untuk membuat checkout. Lihat yang terpasang dengan /plugin.

> "You can think of a skill as a one reusable process, whereas a plugin is a package that can include skills as well as other Cloud Code capabilities, such as MCPs."
