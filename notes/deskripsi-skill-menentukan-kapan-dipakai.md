# Deskripsi skill menentukan kapan skill dipakai

Claude membaca nama dan deskripsi semua skill lalu mencocokkannya dengan permintaan Anda. Deskripsi harus menyebut apa yang dikerjakan skill dan kapan memakainya. Kalau deskripsinya bagus, Anda tidak perlu mengetik nama skill; Claude memuatnya sendiri.

> "a weak description is going to be the main reason that a skill doesn't trigger when you expect it to"
