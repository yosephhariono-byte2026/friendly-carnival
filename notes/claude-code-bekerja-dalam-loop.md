# Claude Code bekerja dalam putaran: kumpulkan, kerjakan, cek

Hampir setiap tugas mengikuti putaran yang sama: Claude mengumpulkan informasi (membaca file, menjalankan tes), mengubah sesuatu, lalu mengecek hasilnya. Kalau masih gagal, hasil cek itu jadi informasi baru dan putaran diulang.

> "Gather context, take action, and then verify the result."
