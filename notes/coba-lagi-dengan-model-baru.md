# Coba lagi masalah lama dengan model baru

Kalau ada masalah yang dulu gagal diselesaikan AI, coba lagi setiap kali model baru keluar. Contoh dari Boris Cherny (pembuat Claude Code): menulis ulang runtime Bun dari bahasa Zig ke Rust gagal di model lama, lalu berhasil (11 hari berjalan, dengan arahan) dan kini dipakai Claude Code.

> "Cuz even if a previous model didn't, the new one might."
