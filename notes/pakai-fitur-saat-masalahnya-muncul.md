# Pakai fitur saat masalahnya muncul

Jangan mengaktifkan semua fitur Claude Code di awal proyek. Biarkan masalah nyata jadi alasan: izin saat bosan menyetujui hal yang aman, plan mode saat keputusan mahal, skill saat proses berulang, subagent saat kode terlalu besar untuk satu konteks.

> "Instead, let the problem you have create the reason to use that feature."
