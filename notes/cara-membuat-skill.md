# Cara membuat skill

Buat folder .claude/skills/<nama>/ berisi SKILL.md. Nama folder jadi perintahnya (misalnya /build-ui). Di atas file ada header berisi name dan description, lalu langkah-langkahnya. $ARGUMENTS diganti dengan teks yang Anda ketik setelah perintah. Skill untuk semua proyek disimpan di ~/.claude/skills. Jaga tetap ringkas; bahan besar pindahkan ke file terpisah di folder yang sama.

> "At its simplest, a skill is a folder containing a skill.md file."
