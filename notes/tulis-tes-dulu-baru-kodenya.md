# Minta Claude menulis tes dulu, baru kodenya

Kalau Claude menulis kode dulu lalu tes, tesnya cuma dibuat supaya lolos untuk kodenya sendiri. Itu curang, bukan menguji. Tes juga cukup untuk bagian terpenting saja; model pintar cenderung menguji semua hal dan membuat kode membengkak.

> "Tell Claude to write the test first and then implement."
