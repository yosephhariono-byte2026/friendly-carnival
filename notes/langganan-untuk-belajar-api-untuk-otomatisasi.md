# Langganan untuk belajar, API untuk otomatisasi

Untuk belajar dan proyek biasa, langganan memberi pemakaian yang bisa diperkirakan. API ditagih per token, cocok untuk otomatisasi dan CI, tapi mahal untuk sesi interaktif yang berat. Detail paket bisa berubah, jadi cek halaman harga Anthropic.

> "API billing charges per token instead of a subscription allowance."
