# Baca rencananya sebelum menyetujui

Plan mode tidak berguna kalau rencananya langsung disetujui tanpa dibaca. Cek tabel apa yang dibuat, hubungannya, file yang berubah, dan cara Claude memverifikasi. Rencana yang bagus menyebut bagian kode yang nyata, bukan "tambah database". Tekan Ctrl+G untuk mengedit rencana. Menyetujui rencana otomatis keluar dari plan mode.

> "The cheapest place to fix a wrong decision is in the plan, not after the code is written."
