# MCP hanya perlu untuk alat di luar kode

MCP menyambungkan Claude ke alat lain: GitHub, database, Slack, analitik, deployment, browser. Contoh pemakaian: cari inspirasi desain, isi data palsu untuk tes, riset dokumentasi, tes di browser. Untuk praktik terbaik atau pola kode, cukup pakai skill, tidak perlu MCP. Nilai: A.

> "you only need an MCP when Claude has to directly interact with something outside your code base"
