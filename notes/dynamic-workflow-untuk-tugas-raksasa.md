# Dynamic workflow untuk tugas raksasa

Fitur baru Claude Code menurut Boris Cherny (pembuat Claude Code): cukup katakan "use a workflow", lalu Claude mengatur puluhan sampai ribuan agen secara bertahap (sebagian mengerjakan, sebagian mengecek atau meringkas, lalu menyebar lagi). Cocok untuk tugas besar seperti menulis ulang seluruh kode atau analisis data rumit. Konsekuensi biaya tidak dibahas di video.

> "And all you have to say is use a workflow."
