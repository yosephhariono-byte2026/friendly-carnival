# MCP adalah standar penghubung antara AI dan alat

Kalau setiap aplikasi AI harus membuat sambungan khusus ke setiap alat, tidak akan bisa berkembang. MCP (Model Context Protocol) adalah standar di tengahnya: alat dibuat sekali sebagai server MCP, lalu bisa dipakai aplikasi AI mana pun yang mendukung MCP (misalnya Claude Desktop, Claude Code). Penjelasan Diyi Yang (Stanford, CS329Z kuliah 1).
