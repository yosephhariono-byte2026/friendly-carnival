# RTK meringkas hasil perintah terminal sebelum dibaca agen

RTK adalah program kecil yang dipasang di komputer. Saat agen menjalankan perintah seperti git status atau tes, RTK meringkas hasilnya dulu, misalnya 40 baris jadi 3 baris. Klaimnya: hingga 90% lebih sedikit output pada 100+ perintah. Pasang lalu lupakan; `rtk gain` menunjukkan berapa yang dihemat. Kalau gagal, hasil aslinya tetap ditampilkan.

> "Test runs, diffs, logs and builds are compressed before your agent reads them."
