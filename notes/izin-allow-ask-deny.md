# Aturan izin: allow, ask, deny

Allow: boleh tanpa bertanya. Ask: harus minta persetujuan. Deny: diblokir. Kalau beberapa aturan cocok, deny menang dulu, lalu ask, lalu allow. Simpan di .claude/settings.json proyek. Contoh: izinkan pnpm build dan test, tanya sebelum git push, tolak membaca .env. Lihat aturan aktif dengan /permissions. Jangan asal klik "jangan tanya lagi".

> "And there are three basic rule types: allow, ask, and deny."
