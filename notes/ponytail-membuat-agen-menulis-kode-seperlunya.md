# Ponytail membuat agen menulis kode seperlunya saja

Ponytail adalah satu skill (prompt) yang membuat agen AI berpikir seperti senior developer yang "malas": pakai dulu yang sudah ada sebelum menulis kode baru. Tetapi validasi, penanganan error, keamanan, dan aksesibilitas tidak pernah dipotong. Bisa dipasang sebagai plugin di Claude Code dan Codex, atau disalin sebagai AGENTS.md untuk agen lain. Lisensi MIT. Hanya pasang dari DietrichGebert/ponytail di GitHub.

> "write only what the task needs, and never cut validation, error handling, security, or accessibility"
