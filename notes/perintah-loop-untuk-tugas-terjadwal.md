# Perintah /loop untuk tugas terjadwal

/loop menjalankan tugas berulang dengan jarak waktu tertentu, seperti jadwal otomatis. Contoh dari pembuat video: tiap hari mengerjakan satu issue GitHub dan membuat PR, menyapu kode untuk celah keamanan dan bug lalu mencatatnya sebagai issue, dan mencari ide fitur dari kode, PR, dan issue.

> "It's essentially like an AI cron job."
