# Alat terjadwal cukup menulis ke file, jangan mengirim apa pun

Alat ketujuh dari panduan "Fluent in Claude Code, Part 1" (@Zephyr_hg): minta Claude menjadwalkan laporan mingguan di komputer Anda (cron di Mac atau Linux, Task Scheduler di Windows). Aturannya: hasilnya ditulis ke file dan tidak pernah dikirim ke mana pun. Di langkah inilah alatnya mulai terasa seperti staf.

> "It writes the result to a file and never sends anything."
