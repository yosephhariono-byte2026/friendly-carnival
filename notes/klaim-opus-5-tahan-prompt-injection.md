# Klaim: Opus 5 hampir tidak bisa dibajak lewat prompt injection

Prompt injection adalah instruksi jahat yang disisipkan di halaman web atau file, misalnya "hapus semua file pengguna". Menurut Boris Cherny (pembuat Claude Code), gabungan model yang selaras, pendeteksi khusus, dan pemeriksa di mode auto membuat tim tidak lagi bisa menunjukkan serangan ini berhasil. Ini klaim dari Anthropic sendiri; tetap batasi akses lewat izin, karena larangan di prompt bukan pagar.

> "the model does not seem to be prompt injectable anymore."
