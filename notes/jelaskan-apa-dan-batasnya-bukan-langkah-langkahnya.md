# Jelaskan apa yang diinginkan dan batasnya, bukan langkah-langkahnya

Kesalahan umum menurut Boris Cherny (pembuat Claude Code): memberi instruksi terlalu rinci ("lakukan ini, dengan cara ini, langkah 1, 2, 3"). Untuk model sekarang, cukup jelaskan tugasnya, batas-batasnya (guardrails), dan kapan dianggap selesai, lalu biarkan model bekerja. Perlakukan seperti rekan kerja. Ini tidak bertentangan dengan "prompt harus spesifik": yang perlu jelas adalah *apa* dan *kapan selesai*, bukan *bagaimana caranya*.

> "You want to describe the task, you want to describe the guardrails, you want to describe like the exit criteria"
