# Pembuat library bisa menyediakan skill resmi

Library seperti Better Auth menerbitkan skill yang mengajari agen cara memakai API mereka dengan benar, jadi tidak bergantung pada ingatan Claude soal versi terbaru. Dipasang dengan npx skills add. Tetap periksa isinya.

> "Libraries, such as BetterAuth, can publish skills that teach agents how their APIs and workflows are supposed to be used."
