# Caveman awalnya membuat agen bicara singkat

Caveman bermula sebagai lelucon: membuat agen AI menjawab singkat seperti manusia gua, supaya token lebih sedikit. Lalu jadi populer (120 ribu bintang di GitHub). Versi gratis dan open source (CLI) membungkus Claude Code, Codex, dan lainnya, dengan jawaban lebih pendek dan kompresi konteks. Tidak perlu akun.

> "It started as a joke that made agents talk like cavemen"
