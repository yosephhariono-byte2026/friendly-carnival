# Claude Code punya beberapa tingkat kebebasan (mode)

Manual: bertanya sebelum tindakan yang perlu izin. Edit otomatis: boleh mengubah file tanpa bertanya. Plan: hanya menyelidiki dan merencanakan, tidak mengubah file. Auto: menyetujui banyak tindakan sendiri setelah dicek sesuai permintaan. Ganti dengan Shift+Tab. Pembuat kursus hampir selalu memakai auto.

> "Claude Code can work with different levels of freedom depending on the mode you're using."
