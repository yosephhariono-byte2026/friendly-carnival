# /compact hanya untuk pekerjaan yang sama

/compact meringkas percakapan untuk mengurangi isi konteks tapi tetap melanjutkan pekerjaan. Pembuat kursus jarang memakainya: biasanya saat konteks penuh, fiturnya sudah selesai, jadi cukup /clear dan mulai sesi baru.

> "You only want to use this when you're working on the same work, but you need smaller context."
