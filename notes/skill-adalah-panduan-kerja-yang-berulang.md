# Skill adalah panduan untuk pekerjaan yang berulang

Skill adalah file markdown (SKILL.md) berisi cara melakukan sesuatu yang sering diulang: praktik terbaik, alur kerja, cara riset. Claude memakainya saat cocok, atau saat diminta. Pembuat video menilai A, bisa S kalau dipakai dengan cerdas. Tempat mencari skill: skills.sh. Bawaan Claude Code: code review dan security review. Membaca skill buatan orang lain juga berguna untuk belajar.

> "It's essentially a guide for something you do over and over"
