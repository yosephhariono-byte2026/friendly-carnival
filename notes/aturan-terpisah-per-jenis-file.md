# Aturan bisa dipecah per jenis file

Kalau CLAUDE.md mulai besar, pecah ke folder .claude/rules (misalnya testing.md, database.md, security.md). Aturan bisa dibatasi ke path tertentu, sehingga hanya dimuat saat Claude bekerja di file yang cocok.

> "Claude code also supports the Claude rules, where you can split instructions into separate files."
